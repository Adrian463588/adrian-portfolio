# Design System — Obsidian & Arctic (`Digital Engineering — Kinetic Systems`)

## 1. Visual Philosophy
Cinematic dark-chrome engineering portfolio combining Swiss grid clarity, minimalist editorial typography, and integrated procedural WebGL shaders without boxed cards or decorative AI templates.

## 2. Color Tokens (WCAG 2.2 AA Verified)
| Token | Hex | Role |
|---|---|---|
| `--bg-canvas` | `#08090C` | Obsidian canvas background |
| `--bg-secondary` | `#15171C` | Graphite surface & subtle panels |
| `--bg-surface` | `#1C1F26` | Elevated interactive states |
| `--border-subtle` | `rgba(242, 240, 236, 0.10)` | Architectural hairlines |
| `--border-strong` | `rgba(242, 240, 236, 0.24)` | Active & focus borders |
| `--text-primary` | `#F2F0EC` | Ivory display headings & primary ink |
| `--text-secondary` | `#A7ADB7` | Silver descriptions & body metadata |
| `--accent` | `#65C8F5` | Arctic interactive highlights & accents |
| `--accent-contrast` | `#08090C` | Dark ink on solid `#F2F0EC` / `#65C8F5` CTAs |

## 3. Typography & Layout
- **Display (`--font-display`):** `Space Grotesk` (`clamp(3rem, 6.8vw, 6.2rem)` hero)
- **Body (`--font-sans`):** `Geist` (`1.65` line height)
- **Metadata (`--font-mono`):** `Geist Mono` (selective indices `01..06`, dates, CLI/tech tags only)
- **Layout:** Open horizontal hairline separations (`Selected Work`, `Experience`, `Enterprise Work`, `About`, `Contact`, `All projects.`), zero repetitive rounded SaaS card walls.
